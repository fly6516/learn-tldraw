Research Canvas local trial

1. Extract the whole folder.
2. On Windows, open “Start Research Canvas.cmd”. On macOS or Linux, run
   ./start-research-canvas.sh from the extracted folder.
3. Open http://127.0.0.1:3000/research if it does not open automatically.
4. Open “Setup” and choose “Prepare TeX resources”. Stay online while
   Tectonic prepares the sample. You can check progress or retry in Setup.
5. Choose “Try a writing sample” and “Use example edits”. Follow the sample
   through review, PDF compilation and submission export. No model key is needed.

Keep the launcher window open while editing. The first LaTeX compile might take
several minutes while the bundled Tectonic compiler downloads LaTeX resources.
“Workbench setup” checks whether the compiler is ready.

Your projects stay in your browser at this address. Before changing browsers,
ports or devices, use Project menu → Project Backup → Complete recovery backup.

If port 3000 is occupied, check whether the workbench is already running or
close the other application using that port. To launch on another port, set RESEARCH_TRIAL_PORT before launching. Your
projects remain at the original address. Return to that address or import a
recovery backup to access them.
