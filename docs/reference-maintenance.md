# Maintain references across files

Open **References** in Writing to merge a BibTeX file into an editable
bibliography. The preview lists entries to add and keys already in the project.
Existing definitions stay in place. The additions go to the bibliography draft,
which you can compile with the other drafts or save with Ctrl/Cmd+S. Expand any
custom BibTeX string definitions in the incoming file before merging it.

Choose **Rename key** beside a bibliography entry or **Rename label** in
**Cross-references**. Review the saved files, affected drafts and Canvas links
before applying. A rename updates literal citations or label references and the
corresponding definitions. The preview flags other occurrences for manual
review, such as keys embedded in custom commands. Duplicate definitions and
occupied destination keys need to be resolved first.

Use **Undo reference changes** in the Writing file pane to reverse the last
operation before making further edits. Compiling after a rename checks the
updated manuscript. Existing submission archives continue to contain the
original source bytes.
